Tubit is a desktop video downloader built with Python, PySide6, yt-dlp, and FFmpeg.

Supported websites:
- YouTube
- Instagram

Before running Tubit.exe, please ensure the following:

Requirements
------------
1. Windows 10/11 (64-bit recommended)
2. Internet connection
3. Administrator rights (only if you want Tubit to install/configure FFmpeg automatically)
4. Microsoft Visual C++ Redistributable (recommended)

FFmpeg
-------
Tubit uses FFmpeg to merge high-quality video and audio streams.

If FFmpeg is not detected, Tubit may prompt you to install or configure it.

Notes
-----
- Some high-quality YouTube videos require FFmpeg.
- A JavaScript runtime (such as Deno) is optional. Without it, yt-dlp may warn that some formats are unavailable.
- This warning does not prevent most downloads.

Default Download Folder
-----------------------
Your videos will be saved to:

    C:\Users\<YourName>\Downloads
